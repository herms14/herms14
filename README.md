##  GitHub Account Focus:
Five years ago, this account was all about Infrastructure as Code: Terraform modules, deployments, and a lot of late nights fighting state files. Then AI showed up and started writing better Terraform than I did, faster, without complaining. So the focus moved. Now it's my lab notebook for cloud governance, automation, and agentic AI, all aimed at platforms that can build, guard, and fix themselves. Most of the time, though, it's where I dump my homelab docs and configs: Proxmox, networking, self-hosted services, and the AI agents I'm teaching to babysit it all. Some of it is polished, some of it is half-built, and some of it was probably written by an agent while I grabbed coffee.
